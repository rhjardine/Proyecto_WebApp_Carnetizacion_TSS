INSTRUCCIONES DE DESPLIEGUE - SISTEMA DE CARNETIZACIÓN (SCI-TSS)

Por favor, siga estos pasos estrictamente para evitar errores de conexión
a la base de datos durante la instalación en XAMPP.

PASO 1: BASE DE DATOS (PHPMYADMIN)

Abra XAMPP e inicie los módulos de Apache y MySQL.

Vaya a http://localhost/phpmyadmin

Vaya a la pestaña "Importar" (Import).

Seleccione el archivo: db/01_master_final_spanish.sql y ejecute.
-> NOTA: El script creará automáticamente la base de datos con el
nombre correcto (carnetizacion_tss). NO necesita crearla a mano.

PASO 2: ARCHIVO DE CONFIGURACIÓN (.env)

En la carpeta raíz del proyecto, busque el archivo llamado .env.example.

Renómbrelo para que se llame exactamente .env (sin ninguna otra extensión).
-> Si Windows no le permite nombrarlo .env, abra el archivo con el
Bloc de Notas y elija "Guardar como", coloque el nombre ".env"
(incluyendo las comillas dobles en el cuadro de guardado).

Abra el archivo .env recién creado y verifique estas credenciales:

DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=carnetizacion_tss
DB_USER=root
DB_PASS=

-> IMPORTANTE: Si su MySQL de XAMPP tiene una contraseña, colóquela en DB_PASS.
-> IMPORTANTE: Si su MySQL de XAMPP corre en otro puerto (ej. 3307),
cámbielo en DB_PORT.

PASO 3: DIAGNÓSTICO DE ERRORES

El sistema ahora posee un modo de Depuración Activo (APP_DEBUG=true en el .env).
Si al entrar al sistema arroja un error en la pantalla de Login, el sistema
le mostrará EXACTAMENTE qué está fallando (Ej: "Access denied for user" o
"Connection refused"). Por favor, tome captura de ese error específico y
envíelo al equipo de desarrollo.
