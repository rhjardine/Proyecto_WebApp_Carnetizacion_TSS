Guía de Despliegue Entorno Pre-Productivo (Staging Local)

Proyecto: SCI-TSS
Rol: Senior Full Stack Software Engineer
Objetivo: Establecer un entorno de pruebas idéntico a producción (adaptado para ejecución local en Windows), saneado de scripts de desarrollo y configurado bajo estándares de seguridad web.

1. Requisitos Previos (Infraestructura Local)

Dado que la aplicación será descargada y probada localmente, configuraremos el entorno sobre XAMPP en Windows. Se requiere un equipo con las siguientes características:

Sistema Operativo: Windows 10 o Windows 11.

Entorno de Desarrollo: XAMPP (versión recomendada que incluya PHP 8.x).

Servidor Web: Apache (incluido en XAMPP). Asegúrate de que el módulo mod_rewrite esté habilitado en el archivo httpd.conf de Apache.

Base de Datos: MySQL o MariaDB (incluido en XAMPP).

Motor PHP: PHP 8.x con las extensiones: pdo_mysql, gd (para imágenes/QR), mbstring, curl, json (usualmente habilitadas por defecto en XAMPP, verificar en php.ini si es necesario).

2. Fase 1: Limpieza Estricta del Repositorio (Pre-Despliegue)

Antes de empaquetar la aplicación en el archivo ZIP, debemos crear una copia del proyecto y eliminar los siguientes archivos que representan un riesgo, incluso en un entorno pre-productivo local:

Eliminar Scripts de Administración Peligrosos:

check_admin.php

reset_admin.php

reset_default_passwords.php

Eliminar Scripts de Pruebas de Hashing:

hash.php

get_hash.php

test_hash.php

hash_result.txt

Eliminar Scripts de Parcheo Directo y DB:

check_db.php

db_index_patch.php

fix_endpoints.php

Limpiar Archivos Originales/Respaldos:

assets/js/api.original.js

api/config/config_fixed.php (Asegúrate de haber movido su contenido a config.php antes de eliminarlo)

api/config/cors_fixed.php (Asegúrate de haber movido su contenido a cors.php antes de eliminarlo)

Una vez eliminados estos archivos, comprime el directorio restante en un archivo .zip. Este es el archivo que se descargará en el equipo local.

3. Fase 2: Despliegue en el Equipo Local (Windows/XAMPP)

Descarga y Extracción:

Descarga el archivo .zip generado en la fase anterior en el equipo Windows destino.

Extrae el contenido del .zip dentro de la carpeta htdocs de XAMPP (por defecto suele ser C:\xampp\htdocs\).

Renombra la carpeta extraída a sci-tss (para que la ruta quede como C:\xampp\htdocs\sci-tss).

Configuración de Variables de Entorno (.env):

Dentro de la carpeta sci-tss, haz una copia del archivo .env.example y nómbrala .env (si el sistema no te permite crear un archivo que empiece por punto directamente, puedes hacerlo desde un editor de texto como VS Code o Bloc de Notas al momento de guardar).

Edita el archivo .env con las credenciales locales de la base de datos (ver siguiente fase).

Protección del Archivo .env (Apache):

Asegúrate de que exista un archivo .htaccess en la raíz del proyecto (C:\xampp\htdocs\sci-tss\.htaccess) con el siguiente contenido para bloquear el acceso directo al .env desde el navegador:

<FilesMatch "^\.env">
    Require all denied
</FilesMatch>


Protección del Directorio de Uploads:

Verifica o crea el archivo uploads/.htaccess (C:\xampp\htdocs\sci-tss\uploads\.htaccess) con este contenido para desactivar la ejecución de scripts en la carpeta de imágenes:

# uploads/.htaccess
<FilesMatch "\.(php|php3|php4|php5|phtml|pl|py|jsp|asp|htm|html|shtml|sh|cgi)$">
    Require all denied
</FilesMatch>
php_flag engine off


4. Fase 3: Configuración de la Base de Datos Local

Iniciar Servicios:

Abre el Panel de Control de XAMPP y presiona "Start" en los módulos de Apache y MySQL.

Acceder a phpMyAdmin:

Abre tu navegador y ve a http://localhost/phpmyadmin/.

Crear la Base de Datos:

Ve a la pestaña "Bases de datos" (Databases).

Crea una nueva base de datos llamada scitss_staging y selecciona el cotejamiento (Collation) utf8mb4_unicode_ci. Haz clic en "Crear".

Configurar el Usuario (Opcional pero Recomendado):

Nota: Por defecto en XAMPP, el usuario es root sin contraseña. Puedes usar este para pruebas locales rápidas actualizando el archivo .env, pero para simular mejor el entorno de destino, es mejor crear el usuario.

Si decides crear el usuario: Ve a la pestaña "Cuentas de usuario" (User accounts), haz clic en "Agregar cuenta de usuario".

Nombre de usuario: sci_stage_user

Nombre del host: Local (o localhost)

Contraseña: TuPasswordSeguroAqui

En "Privilegios globales", marca "Otorgar todos los privilegios en la base de datos scitss_staging".

Importar la Base de Datos:

Haz clic en el nombre de la base de datos scitss_staging en el panel izquierdo para seleccionarla.

Ve a la pestaña "Importar" (Import).

Haz clic en "Seleccionar archivo" (Choose File) y busca el archivo 01_master_final_spanish.sql que se encuentra dentro de la carpeta db/ del proyecto (C:\xampp\htdocs\sci-tss\db\01_master_final_spanish.sql).

Haz clic en el botón "Importar" en la parte inferior para ejecutar el script.

Actualizar el .env Local:

Asegúrate de que el archivo .env en la raíz del proyecto tenga la configuración correcta de la base de datos local que acabas de configurar (ya sea con root o con el usuario específico que creaste).

5. Fase 4: Pruebas de Humo (Smoke Tests)

Abre tu navegador web e ingresa a http://localhost/sci-tss/. El equipo debe validar la siguiente matriz:

Prueba de Seguridad (Accesos Indebidos):

Intentar navegar a http://localhost/sci-tss/.env. Debe retornar un error 403 Forbidden o similar.

Intentar navegar a http://localhost/sci-tss/reset_admin.php. Debe retornar un error 404 Not Found (ya que fue eliminado).

Prueba de Autenticación y CSRF:

Iniciar sesión con credenciales de prueba que se encuentren en la base de datos importada.

Validar en la consola del navegador (F12 -> Network) que el token CSRF se maneja correctamente.

Prueba de RBAC (Control de Acceso basado en Roles):

Ingresar con un usuario de rol menor e intentar acceder a páginas o endpoints que requieran mayores privilegios. La API debe rechazar la solicitud.

Prueba de Carga de Archivos:

Intenta subir una imagen desde la sección correspondiente. Verifica que se guarde en la carpeta C:\xampp\htdocs\sci-tss\uploads\.

Prueba negativa: Intenta subir un archivo que no sea imagen (ej. un .txt renombrado a .jpg o directamente un .php). El sistema no debería permitirlo.

Documento generado para fines de despliegue local y pruebas en entorno Windows (XAMPP).
Este procedimiento adapta el proyecto para su validación final antes de cualquier despliegue en un servidor real de producción.
